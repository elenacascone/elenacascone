## Chi sono

Laureata in Fisica e laureanda magistrale in Data Science presso l'Università degli Studi di Napoli Federico II. Porto nella data science lo stesso approccio analitico e rigoroso maturato nella formazione fisica: definire ipotesi verificabili, misurare l'incertezza, non fermarsi al primo risultato plausibile.

Attualmente svolgo un tirocinio di ricerca presso il **CNR**, su un progetto di agricoltura di precisione: analisi di dati da sensori IoT (variabili meteo e della pianta) per l'ottimizzazione dell'irrigazione di un vigneto, con sviluppo di un processo di automazione basato su Machine Learning.

**Lingue:** Italiano (madrelingua) · Inglese (B2 Cambridge, 2019) · Francese (base)

## Progetti

<table>
<tr>
<td width="50%" valign="top">

**[Classificazione di Oggetti Celesti — SDSS](https://github.com/elenacascone/sdss-celestial-classification)**

Confronto tra quattro modelli di classificazione multiclasse (Logistic Regression, KNN, Decision Tree, Random Forest) su dati fotometrici SDSS DR14, con feature engineering via PCA e inferenza statistica tramite bootstrap.

Risultato: Random Forest, 99.1% di accuratezza sul test set.

`Python` · `scikit-learn` · `PCA` · `Bootstrap`

</td>
<td width="50%" valign="top">

**[Previsione della Glicemia — BrisT1D](https://github.com/elenacascone/diabetes-glucose-forecasting)**

Confronto sistematico tra cinque approcci di forecasting (SARIMA, SARIMAX, Prophet, Gradient Boosting, LSTM), con analisi causale via Cross-Correlation Function e interpretabilità tramite SHAP.

Risultato: SARIMA (walk-forward), MAE 0.42 sul test set finale.

`Python` · `statsmodels` · `Prophet` · `LightGBM` · `TensorFlow`

</td>
